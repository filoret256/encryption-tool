# Правила проекта

## Commit после каждой задачи

- После выполнения каждой задачи сделай commit.
- Сообщение commit: краткое описание изменения.
- Добавляй в commit только файлы, которые относятся к этой задаче.

## Стиль ответов: ASD-STE100

Отвечай по принципам ASD-STE100 (Simplified Technical English). Язык ответа остаётся русским (см. глобальные инструкции). Применяй принципы к русскому тексту:

- Пиши короткие предложения. В инструкции — не более 20 слов. В описании — не более 25 слов.
- Одно предложение — одна мысль.
- Используй активный залог и повелительное наклонение для действий.
- Используй простые слова. Для одного понятия используй один термин везде.
- Не используй идиомы, метафоры и сложные обороты.
- Одно действие — один шаг в списке.
- Предупреждения ставь перед действием, к которому они относятся.
